## 🌐 Task 1: Multilingual Translation Tool

A Streamlit-based web app that translates text between 10 languages (English, Hindi, French, Spanish, German, Italian, Japanese, Chinese, Arabic, Bengali) using the deep-translator library, with a simple language-selector interface, one-click Translate/Clear buttons, and a copyable output box.

**How to Run**
```
cd Task_1_TranslationTool
pip install -r requirements.txt
streamlit run app.py
```

---

## 🎓 Task 2: CampusConnect – FAQ Chatbot

A Streamlit-based FAQ chatbot covering 6 categories (Admissions, Academics, Fees, Campus, Student Services, Placements), using exact-match → similar-question match → keyword match logic (via Python's difflib) to answer queries, with a chat-style interface, chat history, and a Clear Chat option.

**How to Run**
```
cd Task_2_CampusConnect
pip install -r requirements.txt
streamlit run app.py
```
