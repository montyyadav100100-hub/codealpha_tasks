FAQ CHATBOT – CAMPUSCONNECT

PROJECT DESCRIPTION
CampusConnect is a web-based FAQ chatbot designed to provide
quick answers to common college-related questions.

FEATURES
- Interactive chatbot interface
- Frequently Asked Questions
- Multiple FAQ categories
- Admissions information
- Academic information
- Fee-related information
- Campus facilities information
- Student services information
- Placement information
- Similar-question matching
- Chat history
- Clear chat option
- Unknown-question handling

TECHNOLOGIES USED
- Python
- Streamlit
- Python difflib library

PROJECT STRUCTURE

app.py
    Main application containing the chatbot interface,
    FAQ database and question-answering logic.

requirements.txt
    Contains the Python dependency required to run the project.

HOW TO RUN

1. Install Python.

2. Open the project folder in the terminal.

3. Install the required package:

   pip install -r requirements.txt

4. Start the application:

   streamlit run app.py

5. Open the URL displayed in the terminal.

EXAMPLE QUESTIONS

- What are the college timings?
- Where is the library?
- How can I pay my fees?
- Is attendance compulsory?
- How can I register for placements?
- Are internships available?
- How can I get my student ID card?

CONCLUSION

CampusConnect provides a simple and interactive way for students
to find answers to frequently asked college-related questions
through a user-friendly chatbot interface.
